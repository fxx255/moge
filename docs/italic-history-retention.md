# 斜体边缘与历史自动清理

共享 Markdown TextView 为字形左右各预留 0.25 em，随字号缩放。Android TextView
内部会把文字裁到 padding 内侧，因此另用透明阴影扩展原生绘制裁切区，不显示阴影。
保留 Compose 外层裁切，避免文字覆盖邻接的图片或表格；不改变斜体内容、选区和复制逻辑。
公式宽度预算同时扣除字形留白。

设置 → 数据新增「自动清理历史对话」和「保留期限」。默认开启、7 天，可选择常用
期限或输入 1–365 天。关闭时取消后台任务，不自动删除历史或附件；期限数值继续保存。
历史页提示会随开关和期限更新。

过期标准：会话更新、任何消息创建和请求更新都达到期限，且未分类、没有关联收藏、
没有 PREPARING/RUNNING 请求。收藏或分类的对话长期保留，题册快照也保留。
置顶只控制排序，不等同收藏。取消分类或移除最后一条收藏后恢复按期限清理。

查询过期资格与级联删除共享 Room 事务，和收藏、分类、提问写入串行；删除消息、请求
及所有分支选择。随后清理该会话的普通、编辑和分支草稿，再用现有引用扫描回收附件。
其他历史、题册和草稿引用的文件仍保留，扫描失败时不回收文件。

应用启动、设置变化时检查，WorkManager 每 12 小时补充检查，跨进程及重启保留任务。
Android 后台调度时间可能延后，下次启动会补做检查。设置读取失败时不使用默认值删数据。
现有历史同样按最近一次更新及当前设置计算，无数据库结构变更。

验证覆盖真实字体绘制的斜体右侧越界像素、纸张/黑板颜色、大字号、流式解析前缀，
以及过期边界、收藏/分类/在途保护、最近追问或重试、分支级联、大批量删除、共享附件、
开关关闭、期限修改、偏好持久化、设置控件与后台任务去重/取消。
