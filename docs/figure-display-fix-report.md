# 墨格 0.2.1 · 图像显示修复

日期：2026-10-02。版本：0.2.1，versionCode 3。

## 问题与原因

用户截图中，第一轮 SSB 框图可以显示，但答案中的 `[[FIGURE:1]]` 原样露出；第二轮心形线没有显示，绘图 JSON 参数出现在解答里。

原因有两处：旧展示逻辑只认识独占一行的图像锚点；截图中的第二轮回复则将 `"plots":[...]` 写进 JSON 代码块，省略了最外层花括号，旧解析器没有提取出这张图。此前正常结构化回复的多轮测试未覆盖这种实际返回格式。长图导出另有一套仅识别独立行的规则，也存在相同的占位符问题。

## 修改

- 共享图号识别器支持行内和独立行引用，保护普通代码示例、转义文字及未闭合代码围栏。历史上下文和续写编号使用同一套识别逻辑。
- 行内引用显示为“图 n”，图片放在完整文字行之后，保留括号和句号。同一正文重复引用只绘制一次；答案摘要与展开讲解也避免重复显示同一张图。
- 解析器接受经验证的完整绘图对象、正文内 JSON 代码块，以及省略外层花括号的 plots/diagrams 成员片段。保留前后讲解，移除已处理的绘图参数，保留失败图像槽位和原编号。
- 心形线回归样例保存截图中的 25 个采样点，按原采样顺序连接闭合曲线，避免按 x 排序破坏参数曲线。
- 打开已保存的完整异常回答时，若没有现成的成功图像且原文中仍有可识别的绘图参数，在设备本地重新解析、绘制和保存展示结果，无需再次调用模型。保留原始回答；数据库条件更新防止覆盖正在重新生成的答案或已经更改的内容。
- 分享导出使用同一套图号切分，处理行内图号、保留完整句子、避免摘要和讲解的重复插图，并显示可读的缺图提示。

Room 数据库结构仍为 v2。本次可覆盖安装 0.2.0，保留现有历史和设置；图像恢复不是数据迁移。缺少原始绘图参数、参数不可解析或附件已丢失的回答不能保证恢复。
