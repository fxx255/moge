# 墨格 0.2.7 · 公式、阅读位置与拖动界面修改报告

日期：2026-10-03。版本：0.2.7，versionCode 9。基线：0.2.6 / 4a71e14。

## 修改内容与原因

1. **公式识别与兜底**：修复中文出现在 `\text{…}` 中时被误判为普通文字的问题；修复流式回答将数学公式内的 `|` 误认成表格的问题。单独成行、以等号开头且完整闭合的 TeX 推导可补显示定界符，覆盖用户提供的 `=\arcsin\Bigl(2\sqrt{(1-x)-(1-x)^{2}}\Bigr)`。截图中的 `$P_{0|1}=P(\text{判0}\mid\text{发1})$` 保留中文、条件符号和下标，并走原生公式渲染。代码块、价格、普通中文说明和未闭合表达式不做这种补齐。
2. **公式失败显示**：已有失败占位确实存在，但只显示前 60 个字符，诊断日志也曾截断。本次改成按可用宽度换行显示完整 TeX，包括中文和换行；保留完整原始回答与实际尝试渲染的公式，方便定位后续不支持的命令。对未知命令仍明确显示失败原因和完整源码，不把无效公式当作排版成功。诊断保存在设备本地。
3. **导航动画**：左右切页动画只由左右滑动创建，并绑定本次导航的来源、目标记录与方向。系统返回键和普通按钮切页不播放横向动画，避免复用上一回滑动方向。仍遵循系统减少动画设置。
4. **对话阅读位置**：按会话保存首个可见消息 ID、索引和像素偏移；等待历史加载后再恢复。即使导航记录被移除并重新建立，也可恢复原位置。仅真正发送新问题时滚动到新内容，回答更新和重新打开会话不强制跳转。保存最近 80 个会话的位置；消息不存在时回退到有效索引。这里保存的是界面状态，没有修改 Room v3，也没有数据迁移。
5. **浮动输入栏与标题过渡**：对话列表延伸到标题和输入栏下方；输入胶囊带阴影，悬浮在稿纸上，末条内容仍可完整滚到输入栏上方。标题下方用渐变遮罩衔接背景，模糊的是稿纸底层，标题、按钮保持清晰。Android 12 / API 31 及以上使用模糊效果；较低版本保留渐变过渡。
6. **历史与题册拖动**：选中后的批量操作移到单独一行，减轻顶部拥挤。拖到“全部 / 未分类”所在的筛选行即可触发展开，所有分类向下展开为换行卡片；窄屏自动调整卡片宽度，分类较多时允许纵向滚动。保留向上拖入分组提示、原卡片尺寸与内容。下方删除区域占内容区域 30%，弧形凸起边缘向下渐变红色，垃圾桶放在上沿下方；弧形透明角落不会误触删除。
7. **分类管理**：每个分类改为卡片，右端从左到右为改名笔和三线拖动柄。长按拖动柄可预览排序，其他卡片平滑让位；松手后一次性提交相对位置变化，取消时归位。向下拖入删除区域后继续要求确认；删除分类只把题目和历史移至未分类。增加提起、归位和删除动画，防止保存期间重复拖动，并处理拖动中分类被移除、保存失败及仓库延迟更新。列表与新建/改名表单在同一窗口内切换，避免切换窗口时持续布局，并保留列表位置；无障碍改名、上下移动和删除操作也保留。
