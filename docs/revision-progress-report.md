# 墨格 Moge · 本次修改完成报告

日期：2026-10-02

版本：0.2.0，versionCode 2。核心交互、数据结构和分发准备已实现，最终完整检查已通过。本报告取代旧 P7/P8 报告作为本次调整的完成记录，旧报告保留为历史记录。

## 已完成的功能

### 新对话首页与输入

- 启动进入新对话；文字、拍照、相册共用一个输入栏，首次发送后才建立历史记录。
- 相机作为独立输入页面，裁剪、确认后回到原输入框；保留原文字及待发照片，不自动发送或另建会话。
- 修复相机结果写入导航 SavedStateHandle、对话 ViewModel 却监听另一 SavedStateHandle 的连接问题。导航结果与路由参数分开，并在草稿恢复后消费；支持连续两次拍照追加。
- 删除应用内语音输入、录音权限与回答后的快捷追问卡片。

### 多轮图像与答案展示

- 问答使用持久化的消息关联，每条回答保存自己的最终答案和图像槽位。
- 历史上下文不再把旧插图锚点传回模型；新回答从本轮图号 1 开始，仅同一次回答的续写做编号偏移。对明确连续完整的累计图号提供兼容处理。
- 图像解码随实际路径、解析器与修订更新；同规格图缓存的写入和清理串行化，避免显示旧图或读取尚未写完的文件。
- 修复回答已完成但任务尚未释放时过早恢复发送按钮的问题，避免立即追问被 AlreadyRunning 拒绝。
- 设置增加“答案优先”：先显示独立答案，再由用户展开完整讲解；展开在本地进行，不消耗第二次模型请求。无答案字段的普通聊天仍可显示全文。
- 结构化协议增加 answer 字段，流式答案需闭合后才展示。讲解尚未开始就截断时，也能恢复已闭合的答案。
- 解题偏好保留标准解答与帮我查错，删除举一反三。

本轮修复覆盖原有函数图、框图渲染链路，没有增加新的通用文生图服务。

### 独立历史与自定义题册

- 历史自动保存，支持搜索、查看、重命名、置顶和删除。
- 题册只保存用户主动收藏的问答快照；没有预置数学、英语等固定学科。用户可新建、改名、排序和删除分类，并移动收藏。
- 收藏保存题目、识别文字、照片、独立答案、完整解答与图像。删除历史不删除收藏；删除分类将条目保留为未分类。
- 附件清理同时检查收藏引用，避免删除独立快照中的照片或图表。
- 返回已删除的历史页面继续发送保留草稿时，会创建新对话；不会向已删除的会话写入请求。
- 清空题册只清空收藏，保留分类和历史。

数据库直接使用新开发结构（Room v2），按用户要求不实现旧开发数据迁移。旧开发安装需卸载或清理应用数据后再安装；接口配置也需重新填写。后续正式版改变数据库结构时，仍应实现对应的正式版本迁移。

### 横屏相机与图片分享

- 横屏预览与操作区分栏，快门改为圆形；预览和拍摄更新目标旋转，支持两侧横屏。
- 拍照页删除解题模式条，使用设置中的默认偏好；确认页支持继续添加、裁剪、删除、补充说明和使用照片。
- 分享会生成独立浅色长图，包含题目与完整解答或题目与答案；与当前主题和解答折叠状态无关。
- 导出同步完成公式排版，包含表格和图表；宽表格分组保留全部列。普通内容生成一张长图，极长内容按顺序分图，每张高度最多 6000 px，并裁去末尾空纸。
- 提供核对题目、预览、保存全部和系统分享。无照片的追问可以选择是否带上前面的原题照片；不会自动选取一张可能不相关的题目。
- 导出控制内存，取消时清理未完成文件，相册写入失败回滚本次写入。
