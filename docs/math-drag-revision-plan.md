# 公式显示与长按拖动修改方案

日期：2026-10-03。版本：0.2.4 / versionCode 6，基线 0.2.3。

## 公式输入与发送

输入面板保留原始 LaTeX 文本编辑，出现公式时在面板内提供实时排版预览。发送后的用户题目卡复用应用原生 Markdown / LaTeX 渲染器，支持美元和反斜杠定界符；明确的纯公式粘贴可以仅在展示时补公式边界。原始输入、光标编辑、草稿、请求和数据库内容不被显示处理改写。代码、金额和普通文字应避免被识别为公式，未完成或无效的公式仍可继续编辑。宽公式横向滚动，长预览限制高度。

## 长按选择与拖动

历史对话与题册使用相同的长按拖动状态。长按选择一次；选中的卡片再次长按时保持选择，拖动当前选择集合。手指未移动直接抬起只保持选中。

长按时上方显示自定义分类与未分类目标，下方显示红色删除区和垃圾桶。拖入目标时高亮并反馈；达到拖动阈值且在目标内释放时执行移动或删除。拖离目标、手势取消或返回均不执行操作。浮起的稿纸卡片跟随手指，释放时归位或淡出；关闭动效时直接切换。分组条在手指靠近左右边缘时自动滚动，使较多分类也可作为目标。

保留工具栏操作、分类选择弹窗与删除确认，作为无需拖动的操作方式。拖动删除区明确标示释放后的动作。历史删除仍保留正在生成的会话以及独立收藏；题册删除只移除收藏快照，保留历史对话。

## 分类保存

历史对话与题册共用现有用户自建分类，但分别保存归属。历史提供全部、未分类和具体分类筛选及分类管理。数据库增加会话的可空分类外键与索引；删除分类会使相关历史和题册项变为未分类，保留内容。提供 Room 2 → 3 的增量升级以便覆盖当前开发版本，无需清空数据。

## 验证与交付

验证公式原文保留、定界符、金额与代码排除、未完成公式、真实公式渲染；验证长按不拖动、分组移动、红区删除、多选、取消和列表正常滚动；验证分组筛选、事务、在途生成保护和数据库升级。完成检查后生成开发 APK、更新完成报告并同步公开源码仓库。真机键盘输入与手感仍需设备验证。
