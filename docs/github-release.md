# GitHub 分发与应用更新

正式 arm64 APK 与更新清单通过 GitHub Releases 分发，使用专用签名。应用内更新适用于 Android 8.0 及以上的 arm64 设备。正式版可覆盖安装，保留现有应用数据。

## 检查与安装更新

设置中的「版本与检查更新」可以手动检查、查看版本说明和下载更新。应用启动时最多每 24 小时检查一次，有新版时提示用户。下载失败可重试，关闭对话框后下载继续。安装由系统安装器确认，首次安装可能需要授权。

客户端从 GitHub 最新稳定 Release 读取更新清单，默认优先访问镜像，失败时回退 GitHub 直连。更新文件存放在应用私有目录。安装前校验文件大小、SHA-256、包名、版本及签名证书。
