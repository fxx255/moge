# 网络波动恢复（0.6.10）

本轮延续计时和工具调用优化；用户于 2026-10-29 授权验证完成后直接发布。
0.6.9 的首次远端检查遇到打包堆内存不足，收紧构建资源后全量 1688 项中有一项既有
图片测试超时；本地全量也复现该项。测试改为原生图像环境后，两项图片回归通过。
0.6.9 未公开，保留原标签，正式发布使用 0.6.10；生成实现保持相同。

## 默认策略

生成任务仍由应用作用域持有。网络状态变化不会主动取消已建立的连接；现有长读取超时
继续覆盖模型思考和正文停顿。每次发送前检查默认网络是否具有 Internet 能力，未连网时
等待恢复，最长约 60 秒，用户可随时停止。VPN 未被系统标为 validated 不会被直接禁用。

连接阶段最多三次尝试，间隔 1 秒、2 秒。通过网络拦截器在即将发送请求头时保守标记
“可能已提交”，并关闭该请求的透明连接重发。只在尚未到此阶段的临时 DNS、连接、
握手等错误上重试；证书/协议错误不重试。请求头开始、上传中断、等待响应头失败和
响应体断流均不会自动重发原请求。模型请求体标记为一次提交，禁止 HTTP 408/503 及
保留 POST 的重定向触发网络库隐式重发；普通 GET 重定向仍可使用。连接和握手受剩余
等待预算限制，请求开始提交后沿用原有模型读取超时；不会把长推理误限制为 60 秒。
系统 DNS 等阻塞调用的取消仍受系统实现限制，超时后返回也不能再提交请求。

## 可选的一次续写

设置中的“网络恢复后自动续写一次”默认关闭，每次提问捕获开关，生成期间改设置不影响
当前尝试。打开后，只有网络中断且本次请求已有可见正文时，才等待网络并请求一次续写。
只有推理、标题、答案字段或没有响应的请求不会因此静默重发。鉴权、HTTP 服务端错误、
参数错误、用户取消及证书错误也不会触发续写。一次尝试的识题、主回复、补图等共享一个
续写次数上限，第二次中断保留正文和手动入口。

原题、图片归属、模型、提示词、设置保持固定；原题的逐轮上下文也保持原样。一般文本
恢复不重复强制联网搜索。流式桥接先保留已显示正文，再合并未完成段落并处理重叠；
保留原先完整的标题和简明答案。JSON、公式转义和普通聊天分别走原有解码规则。

工具循环在同一个应用任务中保留完整消息、工具结果、推理重放、文档来源和图形槽位，
连接等待及断流续写时继续沿用。已经成功的图片不会因恢复被重新绘制。失败轮尚未完成
的工具调用不执行，也不伪造成功结果。工具链已处理的断流不会再触发外层第二次恢复。
达到工具上限和空答案恢复仍保留各自的界限。

这些工具进度保存在当前应用任务内存中，跨页面有效；本轮没有持久化原始推理或图片
base64。进程被系统终止后，仍以已有正文落盘和手动继续为恢复入口，无法恢复整条工具链。
客户端无法取回服务端已经生成但未送达的片段，续写会产生新的模型调用，可能增加用量，
也仍需核对内容衔接。所有实际模型调用继续逐个汇总 usage；丢失用量的失败轮标为未知，
不会按零消耗处理。总用时包含等待、退避和续写。

网络变更不取消既有流、取消等待、证书失败、长首响应、正文合并、原题图片、前缀与工具
图号、次数和用量、设置快照及任务令牌释放。设备验证限定 MuMu 12-2；实际飞行模式/
