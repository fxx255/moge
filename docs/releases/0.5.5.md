墨格 0.5.5 适用于 Android 8.0 及以上的 arm64 设备，可从现有正式版通过应用内检查更新安装。

- 题目照片改为裁剪确认后在本机后台净化，添加、裁剪和发送无需等待；已发送照片先展示裁剪原图，处理完成后自动替换，失败时继续使用原图。
- 移除自动书页展平与透视校正，仅保留颜色、背景及阴影净化；保留原始分辨率并使用无损 PNG 保存。模型始终使用裁剪后的原图，对话模式不处理，设置中的预处理开关保留。
- 优化照片净化及 PNG 保存速度，降低中间缓冲开销；避免同一照片交接时重复排队，重新裁剪后不显示旧处理结果。
- 双指缩小已移动的裁剪选框时，选框随照片一起缩小，保持所选内容；缩过全图适配大小约 10% 后恢复全图选区，松手快速连贯回弹。统一四边粗细并适当减细，保留原有触控范围。
