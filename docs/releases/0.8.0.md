墨格 0.8.0 修复回答右端文字被截断的问题，并改善列表与引用的段落间距。

- 修复流式更新中列表、引用缩进改变后未正确重新换行的问题，避免中文说明及引用内容超出右侧边界。
- 缩小并统一多段列表中原句、说明、引用与下一条编号之间的留白，普通紧凑列表保持原有间距。
- 保留行内加粗、流式渐显、拖动时持续显示新文字及跨段选择复制；生成结束后继续复用原有文本和布局。
- 覆盖大字号、霞鹜文楷、系统字体、宽窄布局及嵌套列表与引用的排版回归。

适用于 Android 8.0 及以上的 arm64 设备，沿用现有正式签名，可覆盖升级并保留本地数据。相关单元测试及 MuMu 12-2 模拟器回归已通过；小米 17T 等真实手机、息屏及厂商省电行为尚未实机验证。
