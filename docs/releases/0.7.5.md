墨格 0.7.5 修复指数公式显示，调整相机曝光与纸页对焦，并简化分享图片的加入流程。

- 修复公式开头的换行与 `e` 指数表达式被误解为不等号的问题，覆盖流式生成、完整回答、旧历史显示和长图导出。
- 相机曝光控件去掉太阳底圈与滑条背景，改为细轨道和短刻度，保留便于拖动的触控区域；按下快门立即隐藏控件，避免拍照等待时遮挡画面。
- 点按测光默认曝光提高至约 +⅔ EV，并遵守设备支持范围；识别到稳定的亮色文字纸页后尝试自动对焦，手动点按、拖动、缩放和拍照优先。
- 分享图片面板改为「加入当前对话」「加入新题目对话」「加入新对话」三个直接入口，减少一次选择；保留全部图片预览、裁剪与手动发送，兼容横屏、大字体及方格本和黑板主题。

适用于 Android 8.0 及以上的 arm64 设备，沿用现有正式签名，可覆盖升级并保留本地数据。相机曝光与自动对焦的实际效果、息屏及厂商省电行为尚未实机验证。
