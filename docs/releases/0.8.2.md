墨格 0.8.2 新增列表标记选择，精简样式设置，并修复数字序号颜色。

- 设置中保留空心八边形、圆环、圆角菱形、短横线、圆角方框、柔色圆点和经典实心圆点七种样式，选中项及下拉菜单在名称左侧直接展示标记。
- 移除正文示例，大小、描边粗细和列表缩进收进默认折叠的“调整”入口；调整即时反映在标记上，支持自动保存与恢复默认。
- 标记随正文字号、界面缩放和黑白主题同步调整，普通回答、流式回答与导出长图使用一致样式。经典实心圆点随正文颜色显示，黑板主题也清楚可见。
- 数字序号恢复正文颜色，避免同一行中的序号出现不同颜色。

适用于 Android 8.0 及以上的 arm64 设备，沿用现有正式签名，可覆盖升级并保留本地数据。已完成相关单元测试、Lint 和构建检查；真实手机显示效果、息屏及厂商省电行为尚未实机验证。
