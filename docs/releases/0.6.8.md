墨格 0.6.8 修复引用中的公式显示、页面返回状态与图示跳动，并完善文字选择操作。

- 修复 Markdown 引用块内的公式无法正确渲染的问题，兼容多层引用与公式自动换行。
- 修复从已有对话右上角新建后，使用系统返回键可能出现的模式图标和切换状态异常。
- 左上角“新题目 / 新对话”的点击区域包含左侧图标，点击图标也能切换模式。
- 返回回答页面时复用已加载的图示，图片缓存被回收后仍保留原有显示尺寸，避免“图 1”和后续正文重新排版、移动。
- 统一题目和追问文字的选择操作，修复拖动右侧选择端点后范围回弹、长按误触编辑的问题；连续回答支持跨答案摘要和讲解选择文字。

适用于 Android 8.0 及以上的 arm64 设备，沿用现有正式签名，可覆盖升级并保留本地数据。
