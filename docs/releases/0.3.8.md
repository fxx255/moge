墨格 0.3.8 适用于 Android 8.0 及以上的 arm64 设备，可从现有正式版通过应用内检查更新安装。

- 新增按生成多项式绘制的卷积码编码器、循环码编码器和卷积码状态转移图，支持方格纸与黑板主题。卷积码采用教材样图的水平寄存器、上下模二加、抽头和输出换向开关；循环码保留反馈回路、寄存器链及 K₁/K₂ 开关；四状态图采用教材中的扁菱形布局，转移标注为“输出(输入)”。
- 支持点击已发送的追问气泡，修改原文字和附件后再次发送。旧问题、回答及其后续对话完整保留，通过气泡下方左右按钮切换版本；新追问使用当前分支上下文，草稿和阅读位置随分支保存。历史搜索可定位其他分支，分享和收藏使用当前可见分支。
- 修复给文字模型发送图片、且未配置可用看图兜底模型时的闪退。发送前提示检查模型配置，并保留输入文字和图片。
- 升级本地对话数据库，保留已有对话、收藏、附件和模型配置；已保存的结构化编码图会使用新教材样式重新生成。
