墨格 0.4.5 适用于 Android 8.0 及以上的 arm64 设备，可从现有正式版通过应用内检查更新安装。

- 输出额度改为通用协议适配：使用接口能力声明和明确的额度反馈申请最大可用输出，不再按网关或模型名称设置固定上限；兼容 Chat Completions 与 Responses。
- 思考强度统一使用协议参数，按接口声明或明确拒绝做兼容调整；改善仅返回思考、达到上限却没有正文时的恢复，持续有内容的长回答不再被总时长限制中断。
- 星座判决域由完整星座坐标在本地计算，支持单点、多点和全部点；改善等比显示、共享边界、区域配色、点名避让和图例排版。适用于等概、各向同性噪声下的最小距离判决。
- 设置新增「对话中屏幕常亮」开关，默认关闭；开启后在解题与普通对话页面生效，离开页面或进入后台时释放，保留原有主题与圆润控件样式。
