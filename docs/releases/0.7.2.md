墨格 0.7.2 完善分享照片裁剪，修复历史提示、照片按钮和流式编号显示，并简化回答用量统计。

- 修复删除历史对话后，进入其他对话再返回时反复出现旧删除提示的问题；后续删除仍会正常提示。
- 缩小照片右上角的删除圆圈，修复圆圈和叉号被裁切的问题，保留足够的点击区域。
- 从其他应用分享照片并添加到输入框时，先逐张打开裁剪与处理；全部确认后再加入当前或新对话，取消时返回附件面板。
- 修复流式回答首个列表编号在输出过程中不显示的问题，兼容方格本、黑板和大字体。
- 回答底部保留输入、缓存与输出用量，移除请求次数和“本次累计”文字。
- 增加平均输出速度，显示为“平均 xx.x tokens/s”。按本次回答全部输出 token 除以总用时计算，包含接口报告的思考与工具调用输出，以及准备、等待、绘图和保存时间；输出统计或计时不完整时不显示速度。

适用于 Android 8.0 及以上的 arm64 设备，沿用现有正式签名，可覆盖升级并保留本地数据。
