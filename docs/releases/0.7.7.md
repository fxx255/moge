墨格 0.7.7 改善流式生成时的滚动性能，并修复相邻加粗与导出题目公式显示。

- 保留现有流式出字、刷新节奏与渐显动画，拖动查看回答时继续显示新内容；减少长回答的重复扫描、排版与动画路径计算，改善生成过程中的滚动卡顿。
- 保留跨段选字、复制、公式和表格缓冲，以及阅读位置恢复；补充长文本、列表、引用、双向文字、emoji、大字号和关闭系统动画时的回归覆盖。
- 修复相邻加粗片段在流式生成和完整回答中显示异常的问题，不额外插入空格或改变复制内容。
- 导出确认预览与长图中的题目、追问和识别文本支持完整公式；普通文字、代码、金额和未完成公式保留原文。保存与分享继续使用原始 PNG 文件。

适用于 Android 8.0 及以上的 arm64 设备，沿用现有正式签名，可覆盖升级并保留本地数据。滚动优化已通过模拟器回归，实际流畅度仍取决于设备和回答内容；真机效果、息屏及厂商省电行为尚未实机验证。
