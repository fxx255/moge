墨格 0.4.2 适用于 Android 8.0 及以上的 arm64 设备，可从现有正式版通过应用内检查更新安装。

- 新增普通对话模式，保留拍题解题。新对话可选择「解题」或「对话」，发送后固定模式，重新打开历史时自动恢复。
- 普通对话使用自然 Markdown 回复和当前会话上下文，图片直接交给支持看图的主模型，不注入解题提示词，不添加跨会话长期记忆。
- 模式切换采用带滑动下划线的文字页签，输入框和操作按钮统一为小圆角矩形，适配方格本、黑板、大字体、横屏和系统关闭动画。
- 历史卡片显示剩余保留天数，删除多余说明，收藏和分类保护与自动清理规则保持一致。
- 主模型和识题模型改为下拉选择，保留添加、编辑、测试连接和删除操作。
- 加强后台生成的 CPU / Wi-Fi 保护和断网识别，断流保留已生成内容，支持按会话模式继续回答。
- 改善 Markdown 文本选择、边缘滚动、正文转义处理和分享导出，逐步拆分会话解析、模型选择及后台资源管理模块。
