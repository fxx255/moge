墨格 0.3.4 适用于 Android 8.0 及以上的 arm64 设备。

- 新增 Anthropic Messages 原生接口，支持 Claude 文字对话、图片输入、流式回答和识题模型转写。
- 新增 Anthropic 联网搜索协议，支持搜索来源引用、联网测试和原生模型列表。
- 保留多页分享优先生成长图、历史分类同步题册、短距离拖动缩小、Word/PDF/PPT 文档分析及系统文件分享入口。
- 保留紧凑框图布局，图片补充说明统一在对话输入栏中编辑。
- 修复 GitHub 发布草稿刚创建时偶尔无法立即查询到的问题。

使用 Anthropic 时，在模型配置中选择「Anthropic Messages」，填写接口地址及自己的 API Key，并获取或手填服务支持的模型名。联网搜索需要服务端支持并启用相应工具；是否联网由应用的全局联网开关控制。
