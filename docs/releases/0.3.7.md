墨格 0.3.7 适用于 Android 8.0 及以上的 arm64 设备，可从现有正式版通过应用内检查更新安装。

- 修复添加、发送附件后输入框形状和大小变化的问题；题目中的附件改为文件卡片，显示文件类型、名称和大小，点击可预览。
- 将拍照、图片和附件入口合并为圆形加号。点击后顺时针展开上方扇形菜单，点击空白处快速逆时针收起。
- 文件预览跟随已保存的方格纸或黑板主题，状态栏同步；统一文件信息卡、圆角阅读区、图片选项和底部翻页栏，支持页码跳转、取消及读取失败后重试。
- 略微增加按钮、选项卡和卡片圆角，使界面风格更加一致。
- 扩展常见通信框图布局，覆盖相干检测、匹配滤波、相关接收、PSK/MASK、OFDM、并行信道和 PCM/TDM 等 16 类样式；支持抽样开关、多端口竖框和并行信号，改善对齐及正交走线，修复 SSB 框图边线不齐的问题。已保存的结构化框图会按新布局重新生成图片。
- 移除 Anthropic Messages 协议与原生 PDF 请求，保留 Chat Completions 和 Responses；PDF 分析统一使用按页读取及页面图像工具。旧协议配置会迁移为 Chat Completions，并保留模型和密钥；原 Messages 服务地址需要改为服务实际提供的兼容接口地址。
