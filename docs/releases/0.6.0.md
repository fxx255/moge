- 修复从旧题目新建页面时，会话模式可能被既有草稿覆盖的问题。新页面继承来源模式，保留待发送内容；恢复草稿完成后才能发送。
- 发送时固定本轮模式，统一用于会话创建、提示词与回答解析。模式不一致时保留输入并提示，避免按另一种模式发起请求。

- 明确按题目所属学科讲解、保留必要教学步骤，不主动复述题面，不将内部思考草稿写入解答；追问结合前文，围绕本轮问题回答。
