墨格 0.3.6 适用于 Android 8.0 及以上的 arm64 设备，可从现有正式版通过应用内检查更新安装。

- 改进微信等应用“其他应用打开”和系统分享的文档接收兼容性，将文件加入独立的新对话草稿，并保留原有草稿。
- 输入框上方以椭圆浮动附件卡片显示文档，左侧为文件类型图标，中间显示文件名，右侧可移除附件；点击卡片可查看文件。
- 支持在对话输入框中直接粘贴复制的图片，可通过长按“粘贴”或外接键盘 Ctrl+V 添加。图片与文字可一起发送，未发送的图片随草稿保存。
- 分享图片提升至 2160 像素宽、2 倍分辨率，保持稿纸排版比例，并改善题目照片的导出细节。
- 优化应用内长图预览，按可见区域加载高清内容，避免长图整体缩小导致模糊；支持双击放大、上下滚动及横向查看细节。
- 超长分享图片采用分段渲染，控制内存占用；优先生成一张长图，极长内容仍按页码连续分图。
