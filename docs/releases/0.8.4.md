墨格 0.8.4 新增对话合并导出 PDF，并修复部分加粗、长句换行与文本选择问题。

- 题册和历史记录右上角新增 PDF 导出入口，可逐项选择、按科目和日期筛选、选择筛选结果或全选，支持由新到旧、由旧到新排序。更换筛选条件会保留已选记录，便于跨科目合并。
- 所选记录合并为一个 A4 PDF，自动分页后直接打开系统分享；保留当前可见分支的追问、题目照片、公式、表格和生成图，未完成回答会标明已保存内容。题册使用收藏时保存的快照。
- 导出选择界面适配方格本、黑板主题及大字号、界面缩放，支持进度显示、取消和重试。
- 修复中文加粗与相邻斜体标记组合时部分文字未加粗的问题。
- 对整段放在 LaTeX 文本命令中的普通长句恢复正文排版，支持自动换行和局部选择，避免长英文句子超出屏幕。

适用于 Android 8.0 及以上的 arm64 设备，沿用现有正式签名，可覆盖升级并保留本地数据。相关单元测试、Lint、Debug 构建及 MuMu 12-2 的 PDF 生成、文件读取和日期筛选测试已通过；真机息屏及厂商省电行为尚未验证。
