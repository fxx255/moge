墨格 0.3.5 适用于 Android 8.0 及以上的 arm64 设备，可从现有正式版通过应用内检查更新安装。

- 文档作为原始附件保存和展示，不再将提取的正文填入输入框。支持 PDF、DOCX、PPTX、XLSX，模型按需读取页、章节、表格、图片或检索内容，回答来源可以点击查看，追问和收藏保留文档引用。
- 微信等应用分享文件，或通过系统“打开方式”选择墨格，会将附件加入独立的新对话草稿，并保留已有对话草稿。
- 支持具备相应能力的接口接收原生 PDF；可在模型配置中确认 PDF 支持。其他情况按页读取，不再只读取 PDF 前几页。
- 删除输入框公式渲染预览，保留发送后的题目和答案公式渲染；修复加粗内容中 `$2t$` 等行内公式的识别与源码兜底。
- 将接口协议与联网开关分开配置，支持 Chat Completions、Responses 和 Anthropic Messages；修复 Anthropic 搜索暂停后携带完整响应继续请求的流程。

文档上限为单文件 50 MB、每次 8 个附件；原生 PDF 请求总预算为 18 MB，超过后按页读取。Word/PPT 支持结构及内嵌图片读取，尚不提供完整排版转换；旧版 DOC/PPT/XLS 请先转换为新格式。文档分析显示读取进度，回答完成后统一展示。

Anthropic 联网修复通过了模拟协议测试，尚未在用户的实际服务端验证；联网及文档工具能力取决于所选模型和接口。
