墨格 0.5.1 适用于 Android 8.0 及以上的 arm64 设备，可从现有正式版通过应用内检查更新安装。

- 修复拖动分类卡片靠近展开分组列表的上下边缘时，手指停住后不能持续自动滚动的问题，方便移动到较远的分类。
- 表格根据每列实际内容分配宽度，减少短内容单元格的无意义留白，尽量完整显示表格；长表格仍支持横向滚动，长图导出使用同样的列宽规则。
- 长公式优先在加减号、集合条件等合适位置分行，支持方括号内的多项式、积分式和带框集合式，保留积分符号、微分项与完整外框，避免整条缩成小字。
- 修复公式源码中的空行导致公式名称与等式分离的问题，并保留分式、矩阵和分段函数的完整结构。
- 公式选择支持按安全的数学单元调整范围并复制对应 LaTeX 原文；高光与手柄对齐实际公式内容，减少居中留白造成的偏移。
- 放大镜按实际公式高度取样，镜内保留选区高光，改善分式、上下标及选择边界的可见性。
