墨格 0.8.1 优化列表标记、图片查看操作与流式图片排版。

- 无序列表改为灰绿色空心八边形标记，轮廓保持严格对称，上下与左右直边略短；黑板主题使用更明亮的灰绿色。
- 标记尺寸、描边和缩进随正文字号及 UI 缩放同步调整，普通回答与流式回答保持一致。
- 图片查看器的保存和分享操作移至独立的黑色顶部工具栏，白色频谱图、框图等图片上也能清楚找到操作入口，工具栏不再遮挡图片内容。
- 图片生成中的占位高度改为随回答栏宽度按比例调整，减少生成完成前后的高度差异。

适用于 Android 8.0 及以上的 arm64 设备，沿用现有正式签名，可覆盖升级并保留本地数据。已完成相关单元测试、Lint 和构建检查；真实手机显示效果、息屏及厂商省电行为尚未实机验证。
