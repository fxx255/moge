墨格首个正式发布版本，适用于 Android 8.0 及以上的 arm64 设备。

- 改善大图片裁剪、旋转、缩放和发送时的内存占用，降低平板闪退风险。
- 历史对话和题库的卡片随拖动距离逐渐缩小，取消拖动时平滑恢复。
- 分类支持卡片内改名，删除区域仅拖动时显示，并调整删除区渐变方向。
- 生成期间增加息屏 CPU 唤醒保护，设置提供后台运行和通知设置入口。
- 中断回答支持“接着生成”，保留已有正文，在原回答位置合并续写内容。
- 启用应用内版本检查和 APK 下载，默认使用 https://ghfast.top/ 镜像，失败时回退 GitHub 直连；安装前检查哈希、版本和签名。

首次安装说明：此版本开始采用专用长期正式签名，无法覆盖此前使用开发签名的同包名版本。若系统提示签名冲突，请先保存需要的内容，再自行卸载开发版并安装正式版；卸载会清除应用内数据。以后正式版本保持同一签名，可通过应用内更新覆盖安装。

鸿蒙设备仍需在系统应用启动管理中允许后台活动；保活不能阻止系统强制结束应用。中断后续写使用已保存正文发起新请求，无法恢复原网络连接。
