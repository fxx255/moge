墨格 0.4.0 适用于 Android 8.0 及以上的 arm64 设备，可从现有正式版通过应用内检查更新安装。

- 修复斜体文字靠近右边缘时笔画被裁切、显示不完整的问题，兼容纸张和黑板主题、大字号及流式回答。
- 在「设置 → 数据」加入「自动清理历史对话」开关，默认开启。关闭后停止自动清理，继续保留全部历史。
- 保留期限默认 7 天，可调整为 1–365 天，也可选择常用期限；从最近一次更新起计算，已有历史同样适用。
- 手动收藏或已分类的对话与题目长期保留，正在生成的对话不会被清理；置顶仅影响排序，长期保留请收藏或分类。
- 清理过期对话时同步移除其分支和草稿，并回收不再使用的附件；其他对话、题册或草稿仍使用的图片和文件继续保留。
