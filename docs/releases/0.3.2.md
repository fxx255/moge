墨格 0.3.2 增加文档分析和历史题册联动，适用于 Android 8.0 及以上的 arm64 设备。

- 支持通过系统分享或应用内选择上传 PDF、DOC/DOCX、PPT/PPTX、XLS/XLSX、TXT、Markdown 和 CSV 文档。
- 扫描型 PDF 会提取页面图像，和文字内容一起交给解题对话分析。
- 历史记录拖动分类后自动加入题册，并同步已有收藏的分类归属。
- 多图分享优先生成更长的单张长图，超长内容按原顺序分页。
- 缩短历史和题册卡片拖动时缩小到最小尺寸的距离。
- 收紧结构图布局，连线交叉保持直角矩形结构。
- 移除图片确认页重复的补充说明输入框，说明统一在对话输入栏中编辑。
