墨格 0.7.4 新增独立正文字号与界面缩放设置，改善宽屏公式换行和解答中的重复称呼。

- 设置新增「显示与字号」：正文字号支持 14～32 多档选择，文字、公式和表格同步调整，默认保持 17。
- 界面缩放独立提供 75%、85%、100%、110%、125%、150%、175%、200% 多档选择，默认保持 100%；控件、文字与原生选区同步缩放，并保留系统字体大小设置。
- 同一等式的加减续行会根据实际可用宽度重新排版，宽屏能放下时自动合并，窄屏重新换行；保留多步等号推导、矩阵和分段函数的必要行结构。
- 改善后续生成的排版，短公式与「代入」「可得」等引导语自然衔接，减少按假定手机宽度预先断行。
- 答案直接给出最终结论，解析直接承接依据和推导，减少重复称呼与问候；仅在澄清、交流或鼓励需要时自然称呼，同轮最多一次。已有回答保留原文。

适用于 Android 8.0 及以上的 arm64 设备，沿用现有正式签名，可覆盖升级并保留本地数据。
