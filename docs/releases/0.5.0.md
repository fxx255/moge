墨格 0.5.0 适用于 Android 8.0 及以上的 arm64 设备，可从现有正式版通过应用内检查更新安装。

- 分类管理采用活页作业纸样式，统一「移动到分类」界面，兼容方格本与黑板主题；移除多余的长按提示，并提供管理分类入口。
- 新建分类直接在列表末尾创建卡片，自动滚动、聚焦名称并打开输入法。
- 分类拖动删除区域缩小并延伸至屏幕边缘，靠近列表上下边缘时自动滚动，底部保留足够空间，方便将任意卡片移到末尾；短列表支持到边缘的回弹反馈。
- 修复悬浮搜索与分类面板顶部缝隙、圆角处露出下方卡片的问题；点击分类后自动微调位置，完整显示选中的分类卡片。
- 历史对话、题册和已保存题目的标题统一使用边缘柔化效果；阅读已保存题目时，背景方格随正文滚动。
- 打开历史对话和题册题目时加入纸页展开动画，并遵循系统动画设置。
- 修复宽屏照片裁剪界面不居中、裁剪框被照片边界遮挡的问题；裁剪框与控制点增加主题色及明暗衬边，在浅色、深色照片上均更清晰。
