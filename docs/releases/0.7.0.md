墨格 0.7.0 改善图片追问的连接稳定性，修复回答完成时的阅读跳动，并完善公式、文字和照片操作的显示。

- 每次生成使用独立连接池，减少追问追加照片时受旧连接影响而失败的情况；延长大图片上传的写入等待，并补充网络错误阶段诊断。
- 流式回答完成、停止或中断时保留正在阅读的位置，兼容草稿收起、答案插入和图表重排；已经展开的讲解保持展开。
- 修复公式中换行后的变量 e 被误显示为不等号的问题，并兼容显示已保存的受影响回答。
- 修复紧贴英文单词的逗号等标点单独加粗时出现多余星号的问题，流式显示、复制和长图导出保持一致。
- 去掉修改输入时与正文重叠的提示文字；照片删除和裁剪按钮增加清晰的底色与边框，兼容方格本和黑板主题。

适用于 Android 8.0 及以上的 arm64 设备，沿用现有正式签名，可覆盖升级并保留本地数据。
