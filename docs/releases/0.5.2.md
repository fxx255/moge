- 解题模式新增题目照片预处理：在本机识别题目后，结合纸间扫描的书页展平与背景净化，再进入裁剪。设置中的“题目图像预处理”默认开启；对话模式跳过，识别不确定或处理失败时保留原图。没有可靠书页结构时保留原有几何，不重绘文字。
- 已发送的题目照片按完整比例、随页面宽度展示，方便直接阅读，仍支持点击查看原图。
- 修复顶部模糊标题栏的点击穿透，避免误打开下方被遮挡的图片；裁剪界面点击空白处不再退出，使用确定或取消按钮完成操作。
- 修复中文标点附近的双星号加粗；改善分步解答中的换行和序号排版，公式自动分行保留原有列表缩进、区间及多行结构。
- 选择手柄拖过另一端时自动交换左右角色；改善空行选区端点位置，减少手柄偏离实际选区的问题。
- 补发图片结合当前对话处理待补充或待修正的部分，减少重复整题作答，同时为纯图片追问保留协议所需的文字内容。
- 修复新建分类拉起键盘时重复滚动的问题；新生成的卷积码框图在延迟器内标注 D₁、D₂ 等标识。
