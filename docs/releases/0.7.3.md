墨格 0.7.3 改善宽屏追问与回答阅读，保留完整历史上下文，并调整回答底部的用量栏。

- 追问气泡随可用宽度调整，较宽屏幕下的长文字和公式可以充分展开。
- 修复较宽屏幕下回答文字被遮挡、上下滚动时部分内容时隐时现的问题。
- 修复流式生成中插入答案摘要及生成结束时阅读位置跳动的问题，保留翻阅位置和正在进行的滚动。
- 追问保留当前分支的完整历史文字、附件顺序和每轮上下文，再追加新内容；移除客户端原有的历史条数与字符截断。
- 支持看图的模型会携带全部可读取的历史用户图片，不再限制为最近两张，并复用原有图片编码。
- 输入、缓存、输出和速度统计移到重新生成、收藏、分享三个图标左侧，空间不足时自动换行；速度单位简化为 tps，兼容方格本、黑板与大字体。

适用于 Android 8.0 及以上的 arm64 设备，沿用现有正式签名，可覆盖升级并保留本地数据。
