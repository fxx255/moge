# 交互与图片分享修改方案

日期：2026-10-02。基线：开源 0.2.2。

## 顶部导航

移除对话页三点菜单。尚未创建会话时，右上角直接显示「历史对话」和「设置」图标；创建或打开会话后显示「新对话」和「设置」。根据实际会话身份切换，不仅判断导航参数。「我的题册」保留独立文字入口，避免移除菜单后失去收藏入口。

## 相机方向反馈

将 CameraX 实际拍摄方向传给控制区，闪光灯、水平仪、相册等图标随方向变化平滑旋转，使用最短旋转路径，兼容两侧横屏、倒置与屏幕旋转锁定。保留现有相机绑定与生命周期；关闭系统动画时立即切换。

## 答案展开

保留「答案优先」设置和本地展开逻辑。将普通按钮替换为稿纸折边：虚线折痕、三角折角与方向提示。点击后完整解答沿折痕展开，配合高度、淡入和折角转动；收起执行反向动画。触控区至少 48dp，提供展开/折叠无障碍状态，关闭动画时直接显示。展开不重新请求模型。

## 分享闪退与视觉

重点修复预览页切换时 Bitmap 的生命周期。已交给 Compose 绘制的图片不能在切页时立即 recycle；重新读取时必须隔离旧页面状态，避免新页面继续拿到已回收的旧图片。快速切换和延迟解码也需覆盖。

分享弹窗沿用应用的方格背景、稿纸卡片、墨蓝/粉笔主题和标题下划。导出图片统一为便于阅读与打印的浅色稿纸：墨蓝标题、黑色正文、浅方格、红色页边线、题目照片纸框与胶带、页码。保留完整公式、图表、宽表格和长图分页，不通过屏幕截图导出。失效照片应显示明确提示。

## 更新状态

GitHub 源码仓库和自动检查已启用；应用包含检查、下载校验、系统安装和正式发布工作流。0.2.2 仍使用开发签名，更新入口关闭。正式更新需建立专用长期签名、配置 github-release Secrets，并发布带 APK 和 update.json 的正式 Release；用户确认下载与系统安装，不做无确认安装。本次不将开发 APK 作为正式更新包发布。

## 验证

新增多图连续切换、延迟解码与位图存活回归；验证新旧对话图标、展开中间帧与关闭动效、相机方向；检查稿纸导出真实像素。完成相关测试后运行完整单元测试、Lint、debug/release 构建，输出修改报告和可安装 APK。方向动画及真实设备截图仍需实际设备观察。
