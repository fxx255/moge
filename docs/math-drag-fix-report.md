# 墨格 0.2.4 · 公式显示与长按拖动修改报告

日期：2026-10-03。版本：0.2.4，versionCode 6。

## 公式输入与消息

输入框保留可编辑原文，在同一个输入面板内增加可收起的公式排版预览。首次题目与后续追问都使用现有原生 Markdown / LaTeX 渲染器，支持 `$...$`、`$$...$$`、`\(...\)`、`\[...\]`。明确的纯公式（如 `\frac{1}{2}` 或 `x^2`）可以只在显示时补公式边界。

原始输入仍用于编辑、草稿、复制与模型请求。渲染后的用户题目提供“复制题目原文”操作。普通文字、金额、路径、代码不自动建立公式预览；未完成公式使用原文提示并继续编辑。预览最多显示前 6000 个字符、高度不超过 160dp，宽公式可横向查看，发送仍保留全文。

## 历史与题册拖动

长按卡片进入选择并显示目标区域；未移动直接松手只保持选择。已经选择的卡片再次长按不会取消选择，可以拖动当前选择集合。普通短按依然打开内容或切换选择，快速滑动仍滚动列表。

上方出现自建分类和“未分类”目标。手指进入目标后高亮，靠近两侧可自动滚动查看更多分类。下方出现红色删除区和垃圾桶，进入后显示“松手删除 N 项”。只有移动超过阈值且在目标内释放，才执行相应操作；移开、取消手势或返回均不执行移动和删除。

稿纸卡片浮起并跟随手指，源卡片变淡；释放后归位或向目标淡出，列表变化有位置动画，关闭动效时直接切换。工具栏与弹窗仍可完成移动、删除、重命名和置顶。

拖动删除历史沿用在途生成保护及草稿清理，不删除独立收藏；移出题册只删除收藏快照，保留历史对话。工具栏删除仍需确认，拖动删除以明确的红色区域和松手动作执行。

## 分组持久化

历史与题册共用用户自建分类，但独立保存归属。历史新增分类筛选与管理；移动不修改历史时间、消息或收藏快照。无效目标在事务内拒绝，跨批次移动整体提交或回滚。删除分类将相关会话和收藏移至未分类，保留内容。

Room 从 2 升至 3，只增加历史分类外键和索引，注册 2 → 3 的增量升级。回归测试使用实际导出的 v2 数据库验证打开、内容保留、外键行为和再次打开。
