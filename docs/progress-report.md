## P7 实现细节

主要文件为 `ui/notebook/NotebookScreen.kt`、`NotebookViewModel.kt`、`data/db/ConversationDao.kt`、`ConversationRepository.kt` 和 `ui/MogeNavHost.kt`。

- 题册投影由单次 Room 查询获取，隐藏尚未提交的空会话，按置顶和更新时间排序，无逐卡片消息查询。
- 搜索覆盖标题、用户提问、追问及识别文本；`%`、`_` 和反斜杠按字面搜索。关键词与学科条件可组合，未分类和未知学科归入“其他”。
- 点击卡片进入原会话继续解题；搜索、学科和选中项通过 SavedStateHandle 恢复。切换筛选时清除旧选择，防止删除不可见的题目。
- 单选支持重命名，标题允许 1–80 个 Unicode 码点；多选支持全选当前结果和删除确认。
- 删除在数据库事务中筛除 PREPARING / RUNNING 请求，界面也保护当前生成所有者；保留的题目会提示先停止生成。已删除题目的消息、请求级联删除，草稿只为实际删除的题目清理。
- 照片和图表可能与其他题目、草稿共享，因此本轮删除保留这些文件。自动回收孤儿附件尚未实现，长期删除题目后仍可能占用一些存储空间。
- 提供加载、查询失败重试、空题册和无匹配结果状态。常规字号两列，辅助大字号改为一列。

## P8 实现细节

- 新增 `ui/components/PhotoArrival.kt`：新照片从右上方轻落入确认条和题目卡。
- 解答页边线在生成时由上向下描绘，草稿区使用弹簧展开，识别文本可折叠。
- 新增 `ui/theme/Motion.kt`：观察系统动画设置；关闭动画时自定义装饰直接进入完成状态，Compose 动画沿用系统时长比例。
- 照片删除按钮、模式项和快捷追问具有至少 48dp 的触控区域；待发照片的删除操作独立置于缩略图下方，避免与查看操作重叠。页面标题有 heading 语义，操作图标有中文描述。
- 确认面板和相机降级面板可滚动，便于小高度窗口和大字号操作；题册大字号采用单列。
- Markdown / 公式渲染器在主题或字号变化时重建，文字和公式按 Compose 的实际 sp 换算更新；表格宽度估算同步更新。测试覆盖非线性辅助字号映射。
- 修复黑板主题下模式选中态与未配置模型横幅的文字对比；标题荧光笔带只跟随文字宽度。
- 新增 `ui/capture/LevelIndicator.kt`：水平仪支持四种屏幕旋转，平放时忽略不稳定角度，仅在首页前台监听传感器，离开或关闭后注销。硬件水平精度仍待真机检查。
- release 保留 Markwon、JLatexMath、序列化生成器和以名字持久化的枚举，启用 R8 与资源收缩。
- 工程原有方格纸 / 对勾自适应图标和 Android 13 单色图标已核对并随 release 打包，无需额外位图资源。
