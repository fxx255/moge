# 墨格 0.2.6 · 收藏、页面导航与拍照交互修改报告

日期：2026-10-03。版本：0.2.6，versionCode 8。基线：0.2.5 / f597159。

## 本次修改

1. **历史收藏与我的题册**：历史页加入明确的收藏操作，保存每个所选对话最新的完整问答；同一回答去重，已经保存的快照和分类保留。收藏和置顶分别呈现，历史卡片显示已收藏数量。对话内收藏后可通过“查看题册”打开实际保存的条目；直接查看不受先前搜索或分类筛选影响。历史和题册继续使用同一数据库，无结构升级或数据迁移。排查确认原有对话内收藏使用同一张 notebook_entry 表，历史页的图钉动作只做置顶；本次分别提供明确的置顶和收藏入口。
2. **历史卡片**：有封面图片时隐藏文字摘要；没有封面时显示首条用户提问摘要，避免用助手回答填满卡片。保留标题、分类、时间、收藏数量与生成状态。
3. **长按拖动**：保留长按选择；浮层使用原卡片的完整尺寸、内容及已加载缩略图。选中状态不再改变卡片尺寸。拖入上方提示区域后，全部分组向下展开成换行排列，分类名完整显示；超多分组可纵向滚动。下方红色垃圾桶区域保留。隐藏、离屏或已删除的目标不接受放置。
4. **页面导航**：移除提问页“我的题册”文字按钮。在历史顶部和设置加入题册入口。已有对话左滑进入题册、右滑打开新对话；新对话右滑进入历史、左滑返回上一个对话。历史左滑回新对话，题册右滑回对话。相邻页面往返复用原导航记录，保留草稿；上个对话被删除后回退到最近更新的有效对话。手势避开输入栏、图片横向列表、表格和公式横向预览，长按、双指和纵向滚动不触发页面切换。
5. **裁剪与相机**：移除固定比例选项与锁定逻辑，默认自由裁剪，四边和四角分别调整。保留旋转、重拍、原图和确认。裁剪期间移除 CameraX 预览与水平仪，解除相机绑定、停止传感器；关闭裁剪后恢复预览。系统相机备用入口保留。
6. **水平参考线**：将重力传感器转换到当前屏幕坐标后，修正横杆绘制方向；屏幕正角度时右端向下、负角度时右端向上。覆盖四种屏幕旋转方向。
